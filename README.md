FreeSeak
Free online tools — fast, private, no sign-up.

FreeSeak is a growing collection of everyday tools that run entirely in your browser. No accounts, no uploads, no waiting — just open a tool and use it.

Features
Private by design — every tool runs client-side; your text and files never leave the browser
Command palette — press Ctrl+K (or Cmd+K on Mac) anywhere to jump straight to a tool
Instant search — with category filters, matching as you type
Dark mode — light, dark or system
Recent tools — your most-used tools stay one click away (stored locally, never uploaded)
Responsive — same experience on phone, tablet and desktop
Tools
Tool	What it does
QR Code Generator	Create QR codes for links, text and Wi-Fi — download as PNG or SVG
Word Counter	Count words, characters and sentences live as you type
Percentage Calculator	Percentages of numbers, shares and percentage change — instantly
Age Calculator	Exact age in years, months and days — plus your next birthday
Coming soon: Compress PDF, Merge PDF, Split PDF, JPG to PDF, PDF to JPG, Compress Image, Resize Image, Invoice Generator.

Tech stack
Next.js 16 · React 19 · TypeScript
Tailwind CSS 4 + shadcn/ui
