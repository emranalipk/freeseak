# Changelog

| Version | Date | What changed |
| --- | --- | --- |
| 0.7.0 | 2026-11-15 | **Branded downloads** — every file FreeSeak hands back now carries the brand. One shared helper (`brandFilename` in `components/tools/image-utils.ts`) stamps a `-freeseak` suffix on every downloaded filename — extension stays last, filesystem-illegal characters are stripped, length is capped at ~100 chars, and re-processing a downloaded file never stacks markers (already-branded prefix names like `freeseak-qr-code.png` stay untouched). Every download path on the site — all 10 PDF tools, Compress, Resize, Enhance, QR — now flows through it. **ZIP for multiple images**: Compress Image and Image Resizer replace the staggered one-by-one "Download all" (browsers block rapid-fire download bursts) with the same one-click "Download all (.zip)" the PDF tools use; inner zip names are branded too, and duplicates get `-2`, `-3` suffixes so two `photo.jpg` results can never overwrite each other inside the archive; images bundle in fast STORE mode (no pointless re-compression of already-compressed photos). `zipAndDownload`/`loadJsZip` moved to `image-utils.ts` (pdf-utils re-exports them — one download engine for every tool family) and `downloadAllBlobs` is deleted (Rule 1). **Invisible PDF branding**: `savePdf` sets Producer/Creator to `FreeSeak (freeseak.com)` on every PDF every tool generates — it survives filename renames and shows up in PDF viewers' file properties. All ten PDF tools' zip names unified to the `freeseak-*.zip` pattern, fixing `numbered.pdf`/`watermarked.pdf`/`metadata.pdf`/`images.pdf`/`organized.pdf` (.pdf names where a .zip belonged). Enhance downloads unified to the shared helper: `photo-2x-freeseak.jpg` instead of the old `freeseak_photo_2x.jpg` style |
| 0.6.0 | 2026-11-14 | **Enhance Image** — new image tool built on a dedicated enhancement engine (`public/enhance-worker.js`, a dependency-free Web Worker; pipeline: bilateral denoise → auto levels → color adjustments → clarity → bicubic 2×/4× upscale → unsharp-mask sharpen). One-click **Auto-tune** scans noise, blur, exposure, saturation and color cast and sets every slider for the photo; four presets (Auto, Photo, Portrait, Text & Scan); eight adjustment sliders + auto levels; rotate/flip; live debounced preview on a ≤1000 px copy with a draggable Before/After compare slider (peek-the-original button); full-resolution processing only on Download, with a stage progress readout; JPG (quality slider) / PNG / WebP output; copy-to-clipboard as PNG; settings remembered in `localStorage` (`freeseak.enhance.v1`); EXIF orientation honored; safety rails: 30 MB input guard, reduced processing base above 16 MP, results capped at 25 MP. Tool #17, wired through the catalogue (`lib/tools.ts`) → registry → dynamic `[id]` route, so search, /tools grid, category chips, footer Image Tools column and sitemap picked it up automatically; `sparkles` icon key; OG image; engine verified with an 11-point test harness (analysis metrics, 1× pipeline, 2× upscale, 25 MP guard) |
| 0.5.0 | 2026-11-14 | **PDF suite — 10 new tools under a new "PDF Tools" category**, all 100% client-side on a shared engine (pdf-lib edits · pdf.js renders · JSZip bundles, lazily loaded per tool page; pdf.js v6 split workers ship as static assets `public/pdf.worker.min.mjs` + `pdf.renderer.min.mjs`): **Merge PDF** (reorderable queue), **Split PDF** (extract to one PDF or separate files per range/page), **Images to PDF** (JPG/PNG embedded without recompression, fit/A4/Letter pages), **PDF to Images** (PNG/JPG, 1×–3× resolution, progress bar), **Organize PDF Pages** (visual thumbnails: drag-reorder, rotate, delete), **Add Page Numbers** (4 formats, 6 positions, start number, cover skip), **Watermark PDF** (live preview on the real first page, tiled or centred), **Extract PDF Text** (honest no-OCR message for scans), **Edit PDF Metadata** (view/edit/scrub title, author, subject, keywords), **Compress PDF** (safe lossless + strong rasterise modes with before→after sizes and never-worse fallback). Shared PDF infrastructure: lazy loaders, page-range parser with live feedback, zip download, reorderable queues, anchors/colours. Footer gained the PDF column; full SEO sets (intro, how-to, 4 FAQs each) and OG images for all ten tools; new deps in `package.json` installed by the Cloudflare build |
| 0.4.0 | 2026-11-14 | Bluefrog trust layer: operator statements on About and Privacy Policy, "Built by Bluefrog — 10+ years of software experience" in the hero subline, every tool page and the footer copyright, Organization schema renamed to Bluefrog (no sameAs); all queue/coming-soon messaging removed and the catalogue pruned to the 6 live tools (PDF suite + invoice entries deleted, empty PDF category removed, `ready` flag and its dead branches deleted per Rule 1); homepage retargeted (new title, description, keyword H1 "Free, Private Online Tools — No Uploads, No Sign-Up"); new Guides section with the first guide "How to Compress Images Without Uploading Them" (in sitemap); footer version badge `v{SITE_VERSION}` from `src/lib/version.ts` (the lost v0.3.2 work, folded in) |
